## 💫 Tentang Saya:

Saat ini saya fokus pada bidang **Data Science**, **Natural Language Processing (NLP)**, dan pengembangan aplikasi berbasis data menggunakan **Python** serta **PyTorch**. Saya telah menyelesaikan riset klasifikasi dokumen spesifik domain menggunakan model **IndoBERT** serta memiliki sertifikasi **Associate Data Scientist (Ilmuwan Data Madya) – BNSP**.

Saya tertarik berkolaborasi dalam proyek sains data, analisis data, pemodelan *machine learning*, otomatisasi *web scraping*, serta pembuatan dasbor interaktif.

Saat ini saya terus memperdalam eksplorasi pada arsitektur *Large Language Models (LLM)*, *deep learning*, dan rekayasa fitur untuk pemecahan masalah berbasis data!
